前后端分离与非对称加密链路

前端是这份纯静态 HTML/CSS/JS（浏览器直连 TinyWebDB，官方接口开放 CORS）；后端是 D:\OJ 的判题机。

  1. 发布公钥：判题机启动时生成/加载 RSA-2048 私钥，把公钥写进 oj:pubkey。
  2. 前端加密：用 crypto.subtle 的 RSA-OAEP(SHA-256) 分块加密源码（每块 ≤190 字节）， 密文分片写入 code:<SID> 与 code:<SID>:i，同时写入自己的公钥 sub:<SID>.client_pubkey。
  3. 入队：写 sub:<SID> 和 q:<SID>。
  4. 后端轮询：判题机每 3 秒扫描一次队列，发现新提交 → 拉取密文 → 用私钥解密 → 同时把云端 code:<SID> 改成「判题中」并删除密文分片。
  5. 判题：编译 + 逐测试点执行（独立目录、超时/内存/输出监控、任务租约可恢复）。
  6. 结果回传：结果用你的公钥加密后写入 res:<SID>（密文分片 res:<SID>:i）， 并附判题机私钥签名；前端解密 + 用 oj:pubkey 验签。

注意：源码与结果在云端只以密文形式存在，判题机取码后立即清除密文。 客户端私钥保存在浏览器 sessionStorage（关闭标签页即失效）。
